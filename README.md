# Nombre del Proyecto: Mi Página de Música

## Descripción
Este proyecto consiste en una página web informativa sobre la historia del rock y sus bandas más representativas.

## Objetivo
Informar a los estudiantes sobre la evolución musical y fomentar el interés por la cultura del rock clásico.
